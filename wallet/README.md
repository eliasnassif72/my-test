# نظام المحافظ — Elias Control

نظام محاسبة بالمحافظ: لكل مستخدم محفظة يسجّل منها مصاريفه (تُخصم من رصيده)، والمحافظ تُغذّى من **المحفظة الرئيسية** التي يديرها مدير النظام.
نفس تقنية Perfection CRM: **PHP 7+ · MySQL · PDO · واجهة عربية RTL** — يُرفع عبر cPanel بدون أي مكتبات.

## المزايا

| | |
|---|---|
| 🏦 **المحفظة الرئيسية** | المدير يودع فيها رأس المال، ويسحب منها |
| 💸 **تغذية المحافظ** | تحويل من الرئيسية ← محفظة المستخدم (أو إرجاع للرئيسية) |
| ➖ **المصاريف** | مبلغ + تصنيف مسبق + تاريخ + بيان + صورة إيصال اختيارية — تُخصم فوراً من الرصيد |
| 🏷️ **تصنيفات مسبقة** | 11 تصنيفاً افتراضياً (وقود، طعام، قرطاسية…) قابلة للتعديل والإضافة والإيقاف |
| 🔐 **دخول بيوزر وباسوورد** | المستخدم يرى محفظته فقط — المدير يرى كل شيء |
| 📊 **داشبورد** | للمدير: رصيد الرئيسية + كل المحافظ + مصاريف الشهر حسب التصنيف. لكل محفظة لوحة خاصة بكشف حساب شهري |
| 📒 **التقارير** | فلترة بالمحفظة/التصنيف/الفترة + تصدير CSV (يفتح بالعربي في Excel) |
| ↩️ **إلغاء الحركات** | المدير يلغي أي حركة فيُعاد الرصيد تلقائياً (التحويل يُلغى بطرفيه)، وتبقى ظاهرة «ملغاة» مع السبب للتدقيق |
| 🔗 **الربط مع elias controle** | ويدجت iframe جاهز + API بصيغة JSON بمفتاح سري |

**الحماية:** لا يمكن صرف أكثر من الرصيد (قابل للتغيير من الإعدادات) · قفل الصفوف يمنع خطأ الرصيد عند حركتين بنفس اللحظة · CSRF على كل النماذج · حد 5 محاولات دخول خاطئة / 5 دقائق · كل الجداول `utf8mb4` صراحةً · الإيصالات محجوبة عن الرابط المباشر.

## التركيب على السيرفر (cPanel)

1. **cPanel ← MySQL Databases:** أنشئ قاعدة بيانات ومستخدماً واربطهما بكل الصلاحيات (مثال: `perfecti_wallet`).
2. ارفع مجلد `wallet/` كاملاً إلى `public_html/wallet/` ← فيصبح الرابط `https://perfectionsyria.net/wallet`
3. انسخ `config.sample.php` باسم **`config.php`** وعدّل `DB_NAME / DB_USER / DB_PASS`.
4. افتح `https://perfectionsyria.net/wallet/install.php` ← أنشئ حساب مدير النظام. (الصفحة تُقفل تلقائياً بعد إنشاء المدير.)
5. سجّل الدخول ← **المستخدمون** ← أضف المستخدمين (تُنشأ محفظة لكل واحد تلقائياً).
6. **تغذية / إيداع** ← أودع في الرئيسية ثم غذِّ المحافظ.

> `config.php` لا يُرفع إلى git ولا يُستبدل عند تحديث الملفات — خاص بكل سيرفر.
> مجلد `uploads/receipts/` يجب أن يكون قابلاً للكتابة (755).
> صفحة بيضاء / خطأ 500؟ اجعل `DEBUG` = `true` في config.php مؤقتاً، اقرأ الخطأ، ثم أعده `false`.

## الربط مع لوحة elias controle

من **الإعدادات ← الربط مع لوحة elias controle** تجد الروابط جاهزة مع المفتاح:

- **ويدجت (الأسهل):**
  ```html
  <iframe src="https://perfectionsyria.net/wallet/widget.php?key=KEY" style="width:100%;height:420px;border:0"></iframe>
  ```
- **API JSON** (لـ n8n أو أي لوحة):
  ```
  GET https://perfectionsyria.net/wallet/api.php
  Header: X-API-KEY: KEY
  اختياري: ?wallet=ID  ?month=2026-10
  ```
  يُرجع: رصيد الرئيسية، كل محفظة (الرصيد، مصاريف الشهر، الوارد، آخر حركة)، الإجماليات، والمصاريف حسب التصنيف.

## قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `wl_users` | المستخدمون (admin / user) |
| `wl_wallets` | المحافظ — `is_main=1` للرئيسية، `user_id` لصاحب المحفظة، `balance` الرصيد الحالي |
| `wl_transactions` | سجل كل الحركات — `amount` موجب للدخول وسالب للخروج، `ref` يربط طرفي التحويل، `voided` للملغاة |
| `wl_categories` | تصنيفات المصاريف |
| `wl_settings` | اسم النظام، العملة، السماح بالسالب، مفتاح API |
| `wl_login_attempts` | حد محاولات الدخول |

الرصيد المخزّن = مجموع الحركات غير الملغاة دائماً — يمكن التحقق منه من **الإعدادات ← فحص الأرصدة**.
